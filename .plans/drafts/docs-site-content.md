## Goal
The site teaches circuitext through live circuits:
- a full-screen playground
- a syntax reference where every rule has an editable example
- a part gallery generated from the real part registry, so it never drifts
- step-by-step tutorials, starting with the 4-20 mA loop into an ADS1115 over a 150 Ω shunt

## Context read
- `.anchor/ANCHOR.md`, `.anchor/templates/plan.md`, `.plans/README.md`, `.anchor/conventions.md`
- On `feat/prototype`:
  - `README.md`: syntax reference table, part-type table, CLI, JS API, Mermaid adapter, KiCad fixups, "How it relates to…", rough edges
  - `examples/loop-4-20ma.ckt`: 24 V loop, 2-wire XMTR, R1 150 Ω 0.1 %, ADS1115 AIN0, giving 0.6–3.0 V over 4–20 mA
  - `examples/voltage-divider.ckt`, `examples/555-blinker.ckt`
  - `src/parts.ts`: `PART_TYPES` with element, value prop, default footprint, pin aliases, and library chips `ads1115` and `ne555` with pin arrangements
- Earlier plans: `docs-site-scaffold-pages-deploy`, `browser-compile-worker`, `circuit-editor-component`, `mdx-circuit-fences-prerender`

## Depends on (detail)
- `mdx-circuit-fences-prerender`: every live example in this plan is written as a ```` ```circuit ```` fence and relies on prerendered SVGs and build-time error checking. The playground page itself needs only `circuit-editor-component`, which comes in transitively.

## Constraints
- **Docs describe shipped behaviour only** (`.plans/README.md` hard rule). No roadmap pages built from plan files. Rough edges are documented as current limitations.
- The `examples/*.ckt` files are the single source for the tutorials, imported raw, so the committed example SVG and KiCad outputs and the docs never diverge.
- The part gallery is generated, never hand-edited. A generator check in CI fails when `PART_TYPES` changes without regenerating.
- Every reference example must compile in the build (enforced by the fence plugin's build-time errors).
- Electrical claims in tutorials have to be correct and show their arithmetic:
  - 4 mA × 150 Ω = 0.6 V and 20 mA × 150 Ω = 3.0 V.
  - The ADS1115 is at ±4.096 V FSR (PGA = 1), which gives 125 µV per LSB.
  - Shunt dissipation is 20 mA² × 150 Ω = 60 mW.
- Content must stay generic: no references to private or downstream projects.

## Conventions
MDX pages use the registered components. Generated files carry a "generated by gen-part-gallery, do not edit" header. Scripts are Node ESM with the same Biome rules as the repo.

## Risks
- **Tutorial accuracy on electrical details** (ADS1115 FSR, input range limits, shunt tolerance). Mitigation: show the numbers explicitly, cite the datasheet section names, and have the owner review the 4-20 mA tutorial.
- **Gallery pages for every alias bloat the sidebar.** Mitigation: one page per canonical type, with aliases listed on the page.
- **Lighthouse scores are noisy on CI runners.** Mitigation: three runs, median, and assert only performance ≥ 90 and accessibility ≥ 95.
- **README and site content drift.** Mitigation: keep the README short and link to the site for reference once the site is live (owner call, see Open questions).

## Decisions
- **Broken circuit blocks fail the build (2026-10-27).** Any `circuit` fence with errors stops `site:build` with the file, line number and compiler message, so error examples in docs must not use a live `circuit` fence.

## Open questions
